# Technical Documentation Portfolio

A professional engineering portfolio deploying 8 strategic architectural documents. Built using a **Docs-as-Code** framework and an **Information-as-Product** architectural philosophy, this repository engineers documentation for absolute structural integrity, maximum clarity velocity, and seamless deployment.

---

## Technical Stack & Framework

The core infrastructure utilized to design, build, version, and maintain these architectural documents consists of:

* **Development Workspace:** VS Code & Draw.io
* **Authoring Language:** Extended Markdown Syntax
* **Static Site Engine:** MkDocs (Material Theme Architecture)
* **Version Control & Hosting Pipeline:** GitHub
